# Create an Environment

An **environment** is one DuploCloud portal running in your cloud account. You register it in the [DuploCloud Console](console.md), which issues the environment license bound to the portal's hostname. Per-environment agents are also bought for specific environments.

You can create an environment in two ways:

* **Automatically, with the Cloud Deployment Agent.** When you deploy your portal from the DevKit, the agent registers the environment for you.
* **By hand, in the Console.** Open **Environments** and click **Add environment**.

# Overview

DuploCloud is a platform for building and running AI agents that work on your infrastructure: AWS, Azure, GCP, Kubernetes, Git, and the DevOps tools around them. You can use ready-made agents from the Agent Marketplace, or build your own.

These docs explain how to use the platform. They start with a Quick Start that ends in a working agent, then cover the concepts, advanced topics, and best practices for building agents.

## Get started

To get started, install the **DevKit**. It runs the whole platform on your own machine, so you can connect a cloud account and try an agent before anything touches your production environment.

**[Go to the Quick Start →](getting-started/choose-your-path.md)**

# Quick Start

The AWS Extension supports two starting points. Choose the path that matches your situation:

#### Connect to Existing Infrastructure

You already have AWS resources running. Connect DuploCloud to your existing VPCs, clusters, and environments so the AI can start helping you operate and optimize them immediately — without provisioning anything new.
